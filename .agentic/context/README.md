# Context Directory

This directory holds requirement-analysis-stage artifacts produced by the Requirement Analyst:

- `normalized-requirement.json` — structured, labeled requirement (EXPLICIT/INFERRED/ASSUMED/UNKNOWN)
- `requirement-analysis.md` — human-readable narrative of the analysis
- `clarification-questions.md` — produced only when material ambiguity is detected
- `proposed-assumptions.json` — produced only when material ambiguity is detected
- `repo-inspection.json` — brownfield repository inspection notes

Files are created here by the Engineering Orchestrator during a live run. This placeholder keeps the directory tracked in git before any run has occurred.
