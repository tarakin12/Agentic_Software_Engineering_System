# Artifacts Directory

This directory holds major engineering deliverables produced during a workflow run:

- `architecture.md` — Architecture Designer output
- `task-plan.md` — Task Planner human-readable task plan
- `engineering-summary.md` — final engineering summary (Documentation Engineer / Orchestrator)

Files are created here by the Engineering Orchestrator during a live run. This placeholder keeps the directory tracked in git before any run has occurred.
